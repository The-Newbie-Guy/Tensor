# Buku Kating — Kelompok 1 Tensor

Website Streamlit berisi buku kating anggota HMSD Adyatama ITERA 2024.

## 🌐 Live Demo

**https://tensor2024.streamlit.app**

Buka link di atas — tanpa install apa pun. Berisi halaman utama Tensor, 12 buku kating per anggota, kuis Tebak Anggota, dan playground Suara Nama.

## Menjalankan di lokal (opsional)

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt      # Windows
.venv\Scripts\python -m streamlit run main.py
```
